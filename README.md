# MERN Stack Learning Journey

This repository documents my practical learning journey toward becoming a MERN Stack Developer. It contains the exercises, responsive interfaces, UI replication tasks, and React projects completed during my internship and personal practice.

My internship started on **1 July 2026**, and this repository is being regularly updated as I learn new frontend and full-stack development concepts.

---

## Objective

The objective of this repository is to:

- Build a strong foundation in frontend development
- Practise HTML, CSS, Tailwind CSS, and JavaScript
- Learn responsive web design
- Understand React components, props, state, and reusable UI
- Build practical projects based on real website designs
- Progress toward backend development using Node.js, Express.js, and MongoDB
- Become capable of developing complete MERN stack applications
