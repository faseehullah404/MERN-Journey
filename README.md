# MERN Stack Learning Journey

This repository documents my hands-on journey toward becoming a **MERN Stack Developer** during my Summer 2026 Web Development Internship at **Connect Solutions**.

My internship started on **1 July 2026**, and this repository contains the projects, exercises, UI replications, React applications, and full-stack development work completed throughout the learning process.

The journey began with frontend fundamentals and gradually progressed toward React development, advanced responsive interfaces, REST APIs, backend development, MongoDB integration, and frontend-backend communication.

# ▶️ Running the Projects

## Clone the Repository

```bash
git clone https://github.com/faseehullah404/MERN-Journey.git
cd MERN-Journey
```

---

## React Projects

For projects such as:

* `my-first-react-app`
* `property-explorer`
* `i2c-ui-clone`

Move into the project folder:

```bash
cd i2c-ui-clone
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

---

## Task Management System

### Start the Backend

```bash
cd task-management-system/server
npm install
npm run dev
```

The server uses environment variables for configuration and connects to MongoDB before starting.

### Start the Frontend

Open another terminal:

```bash
cd task-management-system/client
npm install
npm run dev
```

The frontend and backend should be running simultaneously for the complete application to work.
